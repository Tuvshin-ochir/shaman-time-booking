# SMS тохиргоо

Систем дараах SMS-ийг автоматаар илгээнэ:

| Хэзээ | Хэнд | Агуулга (загвар) |
|---|---|---|
| Төлбөр баталгаажмагц | Үйлчлүүлэгч | өдөр, цаг, үйлчлүүлэгчийн нэр, утас, хаяг, лавлах утас |
| Төлбөр баталгаажмагц | Бөө | үйлчлүүлэгчийн нэр, утас, өдөр, цаг, үйлчилгээ |
| Цагаас 1 өдрийн өмнө (асаасан бол) | Үйлчлүүлэгч | сануулга |
| Админ цаг шилжүүлэх / цуцлахад (сонгосон бол) | Үйлчлүүлэгч | шинэ цаг / цуцлагдсан |

Текстийг админ самбарын **Тохиргоо → SMS** хэсгээс өөрчилнө. Бөөгийн утасны дугаарыг мөн тэнд оруулна.

## WeSend (wesend.mn) — хамгийн хялбар

WeSend-ийг систем шууд таньдаг тул зөвхөн API түлхүүр хэрэгтэй.

1. https://wesend.mn дээр бүртгүүлж, төсөл (project) үүсгэнэ.
2. **Тохиргоо → Миний бүртгэл** хэсэгт утасны дугаараа баталгаажуулна.
3. **API түлхүүр** хэсгээс шинэ түлхүүр үүсгэнэ. Түлхүүр зөвхөн үүсгэх үедээ бүтнээрээ харагддаг тул тэр даруй хуулж авна.
4. `.env` файлд:

```ini
SMS_PROVIDER=wesend
SMS_API_KEY=WeSend-ээс_хуулсан_түлхүүр
```

5. Серверийг дахин асаагаад доорх «3. Шалгах» хэсгийн дагуу туршина.

Анхаарах зүйл:
- **Туршилтын (trial) төсөл** зөвхөн өөрийн баталгаажуулсан дугаар руу илгээнэ. Бусад дугаарт `trial_recipient` алдаа гарна. Бүх дугаарт илгээхийн тулд ДАН-аар баталгаажуулна.
- Нэг SMS 80₮. Латин үсгээр нэг хэсэгт 150 тэмдэгт, кириллээр 60 тэмдэгт багтах ба кирилл 2.5 дахин үнэтэй. Тиймээс **Тохиргоо → SMS → Латинаар илгээх**-ийг асаалттай байлгана (анхдагч нь асаалттай).
- Үлдэгдэл кредитийг wesend.mn-ийн самбараас харна. Илгээж чадаагүй SMS-ийн кредит буцаж ордог.

## 1. Бусад SMS gateway сонгох

Мобиком, Юнител, Скайтел, Жи-Мобайл зэрэг операторын байгууллагын (bulk) SMS үйлчилгээ, эсвэл SMS агрегатор үйлчилгээ ашиглана. Гэрээ байгуулахдаа дараах зүйлийг шалгана:

- **HTTP API** байгаа эсэх (GET эсвэл POST хүсэлтээр SMS илгээдэг).
- **Илгээгчийн нэр (sender ID)**: байгууллагын нэрээр илгээх бол үйлчилгээ үзүүлэгчээр дамжуулан бүртгүүлнэ. Бүртгэл хэдэн хоног үргэлжилж магадгүй тул эрт эхлүүлээрэй.
- Бүх операторын дугаар руу илгээх боломжтой эсэх.
- Кирилл (Unicode) дэмждэг эсэх. Дэмждэггүй бол «Латинаар илгээх» тохиргоог асаалттай байлгана (анхдагч нь асаалттай).

Үйлчилгээ үзүүлэгчээс **API key**, **илгээгчийн нэр**, **API баримт бичиг** (URL, параметрүүд, амжилттай үеийн хариу) авна.

## 2. `.env` тохиргоо

Систем ямар ч HTTP API-д тохирох загвар ашигладаг. `{to}`, `{text}`, `{from}`, `{key}` гэсэн үгс жинхэнэ утгаараа орлогдоно.

### GET API (хамгийн түгээмэл)

```ini
SMS_PROVIDER=http
SMS_API_KEY=таны_api_key
SMS_SENDER=72720000
SMS_HTTP_METHOD=GET
SMS_HTTP_URL=https://api.example-sms.mn/send?key={key}&from={from}&to={to}&text={text}
```

URL-ийн бүтцийг үйлчилгээ үзүүлэгчийнхээ баримт бичгээс авна. Дээрх нь зөвхөн жишээ.

### POST JSON API

```ini
SMS_PROVIDER=http
SMS_API_KEY=таны_api_key
SMS_SENDER=MyBrand
SMS_HTTP_METHOD=POST
SMS_HTTP_URL=https://api.example-sms.mn/v1/messages
SMS_HTTP_CONTENT_TYPE=application/json
SMS_HTTP_BODY={"from":"{from}","to":"{to}","message":"{text}"}
SMS_HTTP_HEADERS={"Authorization":"Bearer {key}"}
```

### Нэмэлт

```ini
# Дугаарын өмнө 976 залгах шаардлагатай бол
SMS_PHONE_PREFIX=976
# HTTP 200 ирсэн ч алдаа заадаг API бол: хариунд энэ текст байвал л амжилттай гэж үзнэ
SMS_SUCCESS_MATCH="status":"ok"
```

Тохиргоог өөрчилсний дараа серверийг дахин асаана.

## 3. Шалгах

1. Админ самбар → **Тохиргоо → SMS → Туршилт илгээх** хэсэгт өөрийн дугаараа оруулна.
2. **SMS** цэснээс үр дүнг харна: «илгээсэн» эсвэл «алдаа» болон gateway-ийн хариу.
3. Утсандаа SMS ирсэн эсэхийг шалгана.

Хөгжүүлэлтийн үед `SMS_PROVIDER=console` гэж тохируулбал SMS жинхэнээр илгээгдэхгүй, зөвхөн серверийн лог руу бичигдэнэ.

## 4. Зардал хэмнэх

- Латин үсгийн SMS нэг хэсэгт 160 тэмдэгт, кирилл 70 тэмдэгт багтана. «Латинаар илгээх» асаалттай бол текст автоматаар хөрвүүлэгдэнэ (жишээ: «Захиалга баталгаажлаа» → «Zahialga batalgaajlaa»).
- Хаяг урт бол SMS олон хэсэгт хуваагдаж үнэтэй тусна. **Тохиргоо → Байгууллага → Хаяг**-ийг товч бичих эсвэл загвараас `{address}`-ийг хасаж болно.

## 5. Алдаа засах

| Шинж тэмдэг | Шалгах зүйл |
|---|---|
| Бүх SMS «алдаа» | SMS цэс дэх gateway-ийн хариуг уншина. API key, URL, илгээгчийн нэр буруу эсвэл кредит дууссан байж магадгүй. |
| «SMS_HTTP_URL тохируулаагүй» | `.env` дотор `SMS_HTTP_URL` хоосон байна. |
| SMS «илгээсэн» боловч утсанд ирэхгүй | Gateway амжилтгүй байсан ч 200 хариу буцаадаг байж магадгүй. `SMS_SUCCESS_MATCH` тохируулна. Мөн илгээгчийн нэр бүртгэгдсэн эсэхийг шалгана. |
| Бөөд SMS очихгүй | **Тохиргоо → SMS → Бөөгийн утас** хоосон байна. |
