# Цаг захиалгын систем

Бөөгийн үзлэг, засал, мялаалгын онлайн цаг захиалга: нийтийн сайт (mobile-first), QPay төлбөр, SMS мэдэгдэл, админ самбар.

**Технологи:** Node.js 22.16+ (Express 5, EJS), SQLite (Node-ийн суурилагдсан `node:sqlite`). Гадаад хамаарал нь ердөө `express`, `ejs` хоёр. Build алхам, native модуль байхгүй.

## Боломжууд

| Шаардлага | Хэрэгжилт |
|---|---|
| Нийтийн сайт | Нүүр, Үйлчилгээ ба үнэ, Бидний тухай, Холбоо барих, Цуцлах нөхцөл. Утсан дээр доод талд, компьютер дээр толгой хэсэгт «Цаг захиалах» товч байнга харагдана. |
| Хурдан ачаалалт | Сервер талд бэлэн HTML, системийн фонт, гаднын request байхгүй. CSS/JS hash-тай, 1 жил кэшлэгдэнэ. Нүүр хуудас ~12 KB. |
| Facebook (Open Graph) | Хуудас бүрт `og:title/description/image/url`, 1200×630 OG зураг (`public/img/og.jpg`, `npm run og-image`). |
| Захиалгын урсгал | Үйлчилгээ → өдөр (зөвхөн сул өдөр) → цаг (зөвхөн сул цаг) → нэр, утас (формат шалгана) → дүн, нөхцөл → QPay. |
| Цаг барих | Төлбөр хүлээх хугацаанд (анхдагч 15 мин, админаас 5–60) цаг баригдана. Хугацаа дуусахад цаг автоматаар суллагдаж, QPay нэхэмжлэх цуцлагдана. |
| Давхар захиалгаас хамгаалах | Сул эсэхийг `BEGIN IMMEDIATE` транзакц дотор дахин шалгана. Нэг утасны дугаар нэг л цаг барина. «Нэг цагт зэрэг үйлчлэх тоо» тохиргоотой. |
| QPay | Нэхэмжлэх үүсгэх, callback хүлээж авах, `/payment/check`-ээр дахин баталгаажуулах, 30 секунд тутмын нөөц шалгалт. Хоцорсон, давхар төлбөрийг «буцаалт хийх» гэж тэмдэглэнэ. Төлбөрийн түүх хадгалагдана. |
| SMS | Төлбөр баталгаажихад үйлчлүүлэгч болон бөөд хоёуланд, 1 өдрийн өмнө сануулга. Ямар ч HTTP gateway-д тохирно. Кирилл→латин хөрвүүлэлттэй. Бүх SMS лог болж, дахин илгээх боломжтой. |
| Админ самбар | Нууц үгтэй. Самбар, захиалгын жагсаалт ба шүүлтүүр (өнөөдөр, төлсөн, цуцалсан, буцаалт), CSV, цуцлах, цаг шилжүүлэх, гараар захиалга нэмэх, гараар төлбөр бүртгэх, хуваарь, амралтын өдөр, үйлчилгээ ба үнэ, нүүр хуудасны текст, зураг, цуцлах нөхцөл засах, SMS загвар, нөөц хуулбар татах. Нэвтрэх хуудаснаас «Сайт ашиглах заавар» (`/admin/guide`, `docs/ADMIN_GUIDE.md`-аас үүснэ). |
| Хэл, горим | Зөвхөн монгол хэлтэй. Гэгээлэг / бараан горим: анхдагчаар төхөөрөмжийн тохиргоог дагана, ☾/☀ товчоор сонгосныг cookie-д хадгална. |
| Аюулгүй байдал | scrypt нууц үг, HMAC session, CSRF, CSP, rate limit, HSTS. SSL-ийг nginx + certbot хийнэ. |
| Нөөц хуулбар | Өдөр бүр автоматаар (`data/backups`, 14 хоног), `npm run backup`, админаас татах. |

## Хурдан эхлүүлэх (хөгжүүлэлт)

```bash
npm install
npm run dev            # http://localhost:3000
```

- Анхдагч горимд QPay `mock` (төлбөрийн хуудсанд «Төлсөн гэж үзэх (тест)» товч гарна), SMS `console` (лог руу бичнэ).
- Админ: http://localhost:3000/admin, хөгжүүлэлтэд `admin` / `admin123` автоматаар үүснэ.
- Анх асаахад жишээ 3 үйлчилгээ нэмэгдэнэ. Админ самбараас засна.

QPay sandbox-оор шалгах: `.env.example`-ийг `.env` болгон хуулж, `docs/QPAY_SETUP.md`-ийн sandbox утгуудыг оруулна.

## Тушаалууд

| Тушаал | Үйлдэл |
|---|---|
| `npm start` | Сервер асаах |
| `npm run dev` | Файл өөрчлөгдөхөд дахин асдаг горим |
| `npm test` | Тест (цаг тооцоолол, давхардал, барих хугацаа, хоцорсон төлбөр, сануулга, HTTP урсгал, админ эрх) |
| `npm run admin:password -- <нэр> <нууц үг>` | Админ үүсгэх / нууц үг сэргээх |
| `npm run backup [-- <файл>]` | Өгөгдлийн сангийн хуулбар |
| `npm run og-image` | Facebook OG зураг, icon-уудыг байгууллагын нэрээр дахин үүсгэх (Chrome шаардлагатай) |

## Бүтэц

```
server.js              эхлэл: .env, DB, ар талын ажлууд
src/config.js          орчны хувьсагчууд
src/db.js              SQLite холболт, migration, транзакц
src/lib/slots.js       сул цаг тооцоолох (ажлын цаг, цайны цаг, амралт, багтаамж)
src/lib/bookings.js    цаг барих, төлбөр баталгаажуулах, хугацаа дуусгах, цуцлах, шилжүүлэх, сануулга
src/lib/qpay.js        QPay v2 клиент + mock
src/lib/sms.js         SMS илгээх, лог, латин хөрвүүлэлт
src/lib/notify.js      SMS загвар бөглөх
src/routes/            public, booking (захиалга/төлбөр/API), admin
src/i18n/              сайтын анхдагч текстүүд (mn.js), админаас засагдана
views/                 EJS загварууд (views/admin — админ)
public/assets/         CSS, JS
docs/                  админы заавар, QPay, SMS, байршуулах заавар
deploy/                systemd, nginx жишээ
test/                  node:test тестүүд
```
