# Цаг захиалгын систем

Бөөгийн үзлэг, засал, мялаалгын онлайн цаг захиалга: нийтийн сайт (mobile-first), QPay төлбөр, SMS мэдэгдэл, админ самбар.

**Технологи:** Next.js 16 (App Router, React 19), Node.js 22.16+, SQLite (Node-ийн суурилагдсан `node:sqlite`). Хуудсууд server component-оор өгөгдлийн сантай шууд ажиллаж, маягтууд server action-аар хадгалагдана. Гадаад хамаарал нь `next`, `react`, `react-dom` гурав. Native модуль байхгүй.

## Боломжууд

| Шаардлага | Хэрэгжилт |
|---|---|
| Нийтийн сайт | Нүүр, Үйлчилгээ ба үнэ, Бидний тухай, Холбоо барих, Цуцлах нөхцөл, Мэдээ мэдээлэл (`/news`, нүүр хуудсанд гүйдэг картууд). Утсан дээр доод талд, компьютер дээр толгой хэсэгт «Цаг захиалах» товч байнга харагдана. |
| Хурдан ачаалалт | Сервер талд бэлэн HTML (нүүр хуудас gzip ~12 KB), системийн фонт, гаднын request байхгүй. Next.js-ийн CSS/JS hash-тай, 1 жил кэшлэгдэнэ. |
| Facebook (Open Graph) | Хуудас бүрт `og:title/description/image/url`, 1200×630 OG зураг (`public/img/og.jpg`, `npm run og-image`). |
| Захиалгын урсгал | Үйлчилгээ → өдөр (зөвхөн сул өдөр) → цаг (зөвхөн сул цаг) → нэр, утас (формат шалгана) → дүн, нөхцөл → QPay. **Тусгай** төрлийн үйлчилгээнд цаг асуухгүй: амралтын өдрөөс бусад ажлын өдрөөс зөвхөн өдрөө сонгоно (`services.kind = 'special'`, захиалга нь `day_only = 1`, цаг эзлэхгүй). |
| Цаг барих | Төлбөр хүлээх хугацаанд (анхдагч 15 мин, админаас 5–60) цаг баригдана. Хугацаа дуусахад цаг автоматаар суллагдаж, QPay нэхэмжлэх цуцлагдана. |
| Давхар захиалгаас хамгаалах | Сул эсэхийг `BEGIN IMMEDIATE` транзакц дотор дахин шалгана. Нэг утасны дугаар нэг л цаг барина. «Нэг цагт зэрэг үйлчлэх тоо» тохиргоотой. |
| QPay | Нэхэмжлэх үүсгэх, callback хүлээж авах, `/payment/check`-ээр дахин баталгаажуулах, 30 секунд тутмын нөөц шалгалт. Хоцорсон, давхар төлбөрийг «буцаалт хийх» гэж тэмдэглэнэ. Төлбөрийн түүх хадгалагдана. |
| SMS | Төлбөр баталгаажихад үйлчлүүлэгч болон бөөд хоёуланд, 1 өдрийн өмнө сануулга. Ямар ч HTTP gateway-д тохирно. Кирилл→латин хөрвүүлэлттэй. Бүх SMS лог болж, дахин илгээх боломжтой. |
| Админ самбар | Нууц үгтэй. Самбар, захиалгын жагсаалт ба шүүлтүүр (өнөөдөр, төлсөн, цуцалсан, буцаалт), CSV, цуцлах, цаг шилжүүлэх, гараар захиалга нэмэх, гараар төлбөр бүртгэх, хуваарь, амралтын өдөр, тодорхой өдрийн цаг хаах, үйлчилгээ ба үнэ (Энгийн/Тусгай төрөл), мэдээ (форматтай текст засварлагч, зурагтай) нэмэх/засах/устгах, нүүр хуудасны текст, зураг, цуцлах нөхцөл засах, SMS загвар, нөөц хуулбар татах. Нэвтрэх хуудаснаас «Сайт ашиглах заавар» (`/admin/guide`, `docs/ADMIN_GUIDE.md`-аас үүснэ). |
| Хэл, горим | Зөвхөн монгол хэлтэй. Гэгээлэг / бараан горим: Улаанбаатарт нар жаргахад автоматаар бараан болж, нар мандахад буцна (өдөр нь төхөөрөмжийн тохиргоог дагана). Толгой хэсгийн ☀/☾ шилжүүлэгчээр (on/off) сольсон сонголт дараагийн нар мандах/жаргах хүртэл cookie-д хадгалагдана. |
| Амьд тэнгэр | Нүүр хэсгийн зураг дээрх тэнгэр Улаанбаатарын нар, сарны жинхэнэ байрлалаар өөрчлөгдөнө: өдөр нарлаг, орой алтлаг, нар жаргахад улаан, ягаан, шөнө од, сартай (сарны хэлбэр бодит). Минут тутам шинэчлэгдэнэ, `/?sky=21:30` гэж өөр цагийг урьдчилан харна. |
| Аюулгүй байдал | scrypt нууц үг, HMAC session, CSRF (server action-ийн origin шалгалт, зураг оруулахад токен), nonce-той CSP, rate limit, HSTS. SSL-ийг nginx + certbot хийнэ. |
| Нөөц хуулбар | Өдөр бүр автоматаар (`data/backups`, 14 хоног), `npm run backup`, админаас татах. |

## Хурдан эхлүүлэх (хөгжүүлэлт)

```bash
npm install
npm run dev            # http://localhost:3000
```

- Анхдагч горимд QPay `mock` (төлбөрийн хуудсанд «Төлсөн гэж үзэх (тест)» товч гарна), SMS `console` (лог руу бичнэ).
- Админ: http://localhost:3000/admin, хөгжүүлэлтэд `admin` / `admin123` автоматаар үүснэ.
- Анх асаахад жишээ 3 үйлчилгээ нэмэгдэнэ. Админ самбараас засна.

QPay sandbox-оор шалгах: `.env.example`-ийг `.env` болгон хуулж, `docs/QPAY_SETUP.md`-ийн sandbox утгуудыг оруулна.

## Тушаалууд

| Тушаал | Үйлдэл |
|---|---|
| `npm run dev` | Хөгжүүлэлтийн сервер (файл өөрчлөгдөхөд шинэчлэгдэнэ) |
| `npm run build` | Production build (`.next/`) |
| `npm start` | Production сервер асаах (`build`-ийн дараа) |
| `npm test` | Unit тест (цаг тооцоолол, давхардал, барих хугацаа, хоцорсон төлбөр, сануулга, нүүр хуудас засварлагч, цуцлах нөхцөл) |
| `npm run test:e2e` | Build хийгээд жинхэнэ сервер дээр HTTP тест (захиалга → төлбөр, админ эрх, маягтууд, зураг оруулах, CSP) |
| `npm run admin:password -- <нэр> <нууц үг>` | Админ үүсгэх / нууц үг сэргээх |
| `npm run backup [-- <файл>]` | Өгөгдлийн сангийн хуулбар |
| `npm run og-image` | Facebook OG зураг, icon-уудыг байгууллагын нэрээр дахин үүсгэх (Chrome шаардлагатай) |

## Бүтэц

```
src/app/(site)/        нийтийн сайт: нүүр, үйлчилгээ, захиалга (BookForm), төлбөр (PayPanel), захиалгын хуудас
src/app/(admin-panel)/ админ самбар (sidebar-тай): хуудас бүр + actions.js (server action)
src/app/(admin-guest)/ нэвтрэх, сайт ашиглах заавар
src/app/api/, qpay/    JSON API (сул өдөр, цаг, төлбөрийн төлөв), QPay callback
src/proxy.js           CSP (nonce), аюулгүй байдлын толгойнууд
src/instrumentation.js сервер асахад: DB, жишээ өгөгдөл, анхны админ, ар талын ажлууд (src/startup.js)
src/config.js          орчны хувьсагчууд
src/db.js              SQLite холболт, migration, транзакц
src/lib/slots.js       сул цаг тооцоолох (ажлын цаг, цайны цаг, амралт, багтаамж)
src/lib/bookings.js    цаг барих, төлбөр баталгаажуулах, хугацаа дуусгах, цуцлах, шилжүүлэх, сануулга
src/lib/qpay.js        QPay v2 клиент + mock
src/lib/sms.js         SMS илгээх, лог, латин хөрвүүлэлт
src/lib/sun.js         Улаанбаатар дээрх нар, сарны байрлал (амьд тэнгэр, шөнийн горим)
src/lib/news.js        мэдээ (src/lib/rich-text.js: засварлагчийн HTML-ийг цэвэрлэх)
src/lib/notify.js      SMS загвар бөглөх
src/i18n/              сайтын анхдагч текстүүд (mn.js), админаас засагдана
src/components/        толгой, хөл, админы sidebar, маягтууд
src/styles/            site.css, admin.css
public/                зураг, favicon
docs/                  админы заавар, QPay, SMS, байршуулах заавар
deploy/                systemd, nginx жишээ
test/                  node:test тестүүд (test/e2e — жинхэнэ сервер дээр)
```
